## Decisions locked in this session

- One APC has at most one active interruption; all other work is in a visible priority/FIFO queue.
- Default priorities are safety/system 300, operator/user 200, and survey/world opportunity 100.
- Higher-priority work preempts only while the active record is explicitly preemptible.
- A newly offered survey persists for one no-action handoff tick. An operator can preempt during that
  window; the first deterministic survey action marks it non-preemptible.
- Goals, schedules, and cached routes are not overwritten by an interruption. Compact resume context
  is inspectable, and normal sequencing resumes after terminal resolution.
- Active/queue/last-terminal state lives only in each APC's `runtime.json`; malformed records fail
  closed. Restart preserves valid state, Reset day/agents clears it, and regrid cancels survey records.
- The generic API requires an explicit requester/source. It never hardcodes the user's in-world name.
- #38 provides transport and lifecycle only. Chat sessions/transcripts/direction acceptance belong to
  #37; lasting goal insertion/reprioritization belongs to #36.
