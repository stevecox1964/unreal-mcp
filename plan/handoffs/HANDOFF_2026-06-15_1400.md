## Decisions locked in this session

- **Grid cells = world authority, static, true XY** — built once at world-init from `world_grid.json`. Never rebuilt per-agent. The coordinate authority for the whole sim.
- **Place cells = semantic, no raw XY to the cognitive layer** — AIPCs reason in place names, not coordinates. The lizard brain does the name→XY resolution. This is a load-bearing design principle.
- **Place ownership model** — two kinds: APC-owned (write authority belongs to that APC) and community (no owner; any APC can name/enrich). `named_by` in the current schema is not the same as ownership — that distinction needs to be built.
- **Place types are `home` / `work` / `public` / `landmark`** — each agent needs home and work assigned in `state.json`; public/landmark places are community-owned.
- **`master_plan.html` is the living checklist** — it's the go-to artifact for tracking milestone progress. Keep it updated as features land.
