## Decisions locked in this session

- **Milestone 1 is the spine** — the daily planner/sequencer is the next cognitive-loop layer per
  MASTER_PLAN; built loop-safe (LLM injected) then wired live. Don't re-derive.
- **Places are names, not coordinates** — schedule blocks carry place *names*; resolution stays the
  existing `walk_to` named-place path. The planner never declares coordinates.
- **Dufus's distractibility is in-character** — his generated schedule literally includes "get distracted
  by something shiny, chase it"; the reaction-gate tune (#10.5) is about *weighting*, not eliminating it.
- **Push directly** — this session pushes to `origin/auto-loop/backlog` (per `feedback-push-no-prs`), not
  the old "never push unattended" stance; the user is present and directing.
- **One Unreal instance, the user's** — preflight checks one editor owns `:55557` before any run
  (`feedback-single-unreal-instance`).

## Open questions

- **#10.5 reaction-gate weighting** — how strict should the routine destination be vs. reacting to every
  passer-by? Options: (a) **balanced reaction gate** (rec — routine wins unless something salient
  interrupts, then resume; MASTER_PLAN §14), (b) strict (schedule almost always wins), (c) loose (current —
  very distractible). Needs the user's director call.
- **Navmesh `stuck` wedging** — agents still wedge on un-navmeshed obstacles (`stuck on an obstacle`); they
  recover but it stalls progress. Separate robustness item (engine-agnostic-navigation territory).
- **Wake path** — the planner is wired into the *decide* loop; the wake/orient first-action already routed
  to the schedule's place this run, but wake isn't yet explicitly fed the structured directive. Worth
  deciding if it should be.
