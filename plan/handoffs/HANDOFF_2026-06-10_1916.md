## Decisions locked in this session

- **Behavior comes from the mds; code supplies senses only** (time, place, map). User
  rejected coded behavior (bounds clamp) explicitly. Explore mode's deterministic routing
  stays the one exception by design.
- **Block-on-evidence policy**: adjacent-and-obstructed → block immediately; otherwise
  3 consecutive failures; success resets the counter.
- **World clock is config, not code**: `worlds/<level>/world.json`, default 08:00 ×1;
  MCP_World runs ×10 (full day ≈ 2.4 real hours).
- **Wake failure degrades to the authored goal** — never blocks sim start.
- **Never call `get_actors_in_level` for spatial questions** (1.6 MB). Targeted
  `find_actors_by_name`, or dump-to-file + script filter. Compact world query tool is a
  saved TODO, not now.
- **Never issue Unreal MCP calls in parallel** — single-socket bridge, all calls time out.
