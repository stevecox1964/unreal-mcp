## Decisions locked in this session

- **Deterministic frontier explorer, not LLM-driven movement** — cheap, predictable coverage; LLM/VLM only perceives (global rule #5).
- **Per-agent egocentric maps** at `worlds/<level>/agents/<id>/spatial_map.json` — biologically faithful; supports multi-agent.
- **Vision-only place names; engine may seed geometry/bounds only** — preserves "discover by looking"; user: "asking the world for a map is normal — humans do it."
- **Gemini `gemini-2.5-flash-lite` via OpenAI-compat endpoint** — fast (~1.8s), cheap, non-thinking. `gemini-2.5-flash` truncates short JSON; `gemini-2.0-flash` 404s on this endpoint.
- **Engine-agnostic representation is the thesis** — VLM distills Unreal's ~6,700 actors into portable `coords + semantic labels + nav graph`; nothing Unreal-specific in the map. Swap the engine/robot, same pipeline.
- **Sim will own the avatar's position** — persist last *true read* position (not dead-reckoned), teleport onto NavMesh at startup. Build this *after* movement is proven once. Fixes off-mesh spawn + run continuity; persisting truth avoids drift when she's physically blocked.
- **Keep the Dufus avatar** (don't delete) — second test subject for multi-agent; leave inactive (`active_agents=["maren"]`).
