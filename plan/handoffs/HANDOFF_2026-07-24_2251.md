## Decisions locked in this session

- **The offline suite is not the verification step** (user's call, saved to memory). The real test is a live
  Unreal + cockpit run, with Claude scanning logs afterwards. Do not report "N/N passing" as evidence a
  feature works, and do not propose running the suite as the check.
- **The run log lives in `AgentManager`, not `sim_runner.py`** — the log directory is only known once a
  level's agents load, so attaching it at process start would require guessing the level.
- **The run log truncates per run**, matching `agent_decisions.log`. Consistency beat retention; a run worth
  keeping must be copied before the next start.
- **`_attach_run_log` forces the `AgentRuntime` logger to INFO.** Hosts that never call `basicConfig` (web
  UI, MCP) leave root at WARNING, which would drop every INFO record before any handler saw it and make the
  file useless.
- **Excluded agents are logged even for benign reasons** (cooldown), not just suspicious ones. One line per
  tick is cheap; a silently vanishing APC cost a whole run.
