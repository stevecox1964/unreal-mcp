  editor) → community cells (APC-built) → memories.
- **World authoring happens in the editor, not a web UI** — drop/rename actors; `/map` demotes to
  viewer/debug; #16 click-authoring is fallback only; `places.json` stays supported as a second
  source; #21 v2 re-anchor is subsumed (landmark rescan *is* the re-anchor). "We are spending too
  much time trying to code around something that is simple."
- **Author typos are our problem** (#25) — normalize at the scan boundary (casefold, suspects);
  `place_db.py` matching stays untouched.
- **Orchestrator workflow is the default**: spec commit (the why) → executor commit (the what),
  both referencing the backlog number; worktree isolation for parallel executors; Fable reviews
  before push. Worktree executors must fast-forward stale bases first (both handled it well today).
- **"Suite green" ≠ "app launches"** — the suite bypasses `uv`'s build step; anything touching
  `pyproject.toml` needs a `uv run python -c "import web_ui.main"` smoke test in verify.
- This repo is an **application, not a package**: `[tool.uv] package = false` is intentional.
