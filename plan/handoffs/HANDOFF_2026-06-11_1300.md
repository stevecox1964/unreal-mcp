## Decisions locked in this session

- **Behavior from observations, not code**: the LLM must use what it sees (image + spatial context) to pick specific `walk_to` targets. Python code supplies senses, not decisions. User explicitly rejected coded movement logic.
- **`wander` stays in vocabulary** but means "purposeful movement guided by observation," not random. The LLM should output `walk_to direction=forward` rather than `wander` when it wants to keep moving.
- **Log auto-clears on every `start_simulation`** — each run is a fresh log. No archiving.
- **Maren stays at the vegetable truck** (actor `veh_VegitableTruck2`). `reset_agents` now teleports her to the truck position (captured this session).
