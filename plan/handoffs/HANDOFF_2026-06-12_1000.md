## What was done this session

- **Rewrote `Python/agent_runtime/place_db.py`** with a new 3-table schema:
  - `place_cells(col, row, name, named_at, named_by)` — world geography, PRIMARY KEY `(col, row)`. No `agent_id` in PK; `named_by` is attribution metadata only.
  - `place_observations(col, row, direction, landmark, confidence, observation_count, last_seen_by, last_seen)` — compass-indexed landmark facts, PRIMARY KEY `(col, row, direction, landmark)`. `last_seen_by` is attribution metadata only.
  - `agent_visits(agent_id, col, row, visit_count, first_seen, last_seen)` — per-agent visit history, PRIMARY KEY `(agent_id, col, row)`. Used by web UI "who has been where" and wake-skip check.
- **Updated `get_place(col, row)`** — dropped the `agent_id` parameter entirely; reads are fully world-shared.
- **`touch(agent_id, col, row)`** — now writes only to `agent_visits`; no longer touches `place_cells`.
- **`set_name(agent_id, col, row, name, world_time)`** — first-agent-wins; `agent_id` stored as `named_by` metadata.
- **`ingest_compass(agent_id, col, row, direction, landmarks)`** — `agent_id` stored as `last_seen_by` metadata; landmark dedup via `ON CONFLICT DO UPDATE`.
- **Fixed two call sites in `agent_manager.py`**:
  - `agent_manager.py:370` — `get_place(agent.agent_id, col, row)` → `get_place(col, row)`
  - `agent_manager.py:616` — `get_place(agent_id, col, row)` → `get_place(col, row)`
- **Fixed `test_spool_up.py:193`** — second `_wake_agents()` call in the failure-path test was not awaited; changed to `asyncio.run(mgr._wake_agents())`.
- **Verified**: all 25 test checks pass (`scripts/agent_runtime/test_spool_up.py`).

## Decisions locked in this session

- **First-agent-wins for place naming.** Once a cell is named, no subsequent agent can rename it. This keeps the world map stable as avatars accumulate. Deliberate — re-litigate only if you want a confidence/vote model.
- **`agent_visits` is the only per-agent table.** All other place data is world-shared. This was the explicit design goal so Maren's map knowledge transfers to Dufus instantly.
- **Confidence floor = 0.8 for landmark reads.** Low-confidence Gemini outputs are ingested but filtered out of `get_place()` responses. The floor is `_CONFIDENCE_FLOOR` in `place_db.py`.
- **`world_places.db` lives at `worlds/<level>/world_places.db`**, not inside any agent's directory. It is world-scoped, level-scoped.
- **`place_cells` rows without a name are not returned by `get_place`.** A cell that has been visited (in `agent_visits`) but not yet named returns `None` from `get_place`, which triggers a fresh sweep. Only a named cell triggers the skip.

## Open questions

- **Migration of `world_places.db`**: If an old DB file exists from the prior schema (with `agent_id` in PKs), it will fail schema creation silently (tables already exist but with wrong columns). The file is not committed, so it probably doesn't exist in prod — but if you see weird DB errors, delete `Python/worlds/MCP_World/world_places.db` and let it recreate.
