## Decisions locked in this session

* **Entrapment is a perception-MEMORY problem, not a decision problem.** The LLM's
  reasoning was correct on every one of those nine ticks. Do not "prompt it better" —
  find the measurement that got thrown away.
* **No-go memory lives in world coordinates, not "where I am standing".** The one-spot
  ledger (`_record_attempt`) is wiped on movement on purpose; that is right for a
  mailbox and wrong for a building.
* **Two grades of evidence, and they expire differently.** A mind-stated refusal is a
  judgement and keeps forever; a body reading is true of a moment and the parked van
  drives away, so it lapses after 30 min. Nothing is ever deleted — `all_patches` stays
  the whole reviewable record (rule 12).
* **Still facts, not fences** ([[feedback_facts_not_blocking]]). A seal caps how FAR a
  step travels and is read back to the APC. It never overrides the chosen heading.
* **The seal geometry is the design, and small beats generous.** See above — the first
  version traded the SR50 loop for a worse one.
* **Never paint no-go markers into the RGB captures.** The user asked directly. A
  synthetic marker teaches the VLM "marker = stop" and occludes the real cue (the
  fence, the truck). The wanted thing is the *label*: project seals into the frame using
  the camera pose already recorded per capture and write a sidecar JSON. Logged in #91,
  not built.
* **In-world Unreal debug markers: deliberately not built.** They need a new draw
  command plus a plugin rebuild, and would have to be editor-viewport-only.
* **Maren is parked.** User: "Forget about Maren for now."

## Open questions

* **Is `MEASURED_TTL_S = 1800` (30 min real time) right?** Guessed, not measured. Too
  short and a building has to be re-proved every half hour; too long and a moved
  vehicle fences off a street. SR51 will show which way it errs.
* **Should a *shared* wall exist?** Seals are per-APC today (`refused_by`), so Maren
  cannot benefit from a wall Dufus proved. Cheap to change, but it is a real design
  call about whether one APC's body reading counts as evidence for another's.
* **Tests.** Speed mode is still on (no tests until the user says). #91 is flagged
  "needs a test" in the backlog: `dead_end` geometry, the +/-30 degree arc constraint,
  `active_patches` expiry, and the `_patches_along` line scan.
