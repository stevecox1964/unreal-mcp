## What was done this session

- **180° wake sweep** (`agent_manager.py:_wake_sweep`): each agent turns in place through 5 headings (left, forward-left, forward, forward-right, right) via `command_character_teleport`, captures a view at each, restores facing. **Verified live in PIE** — the 3 images checked were genuinely different views.
- **Wake orientation upgraded** (`llm_router.py:_USER_TEMPLATE_WAKE`): built-in system questions (where am I / what time / where should I be), per-view perceived text, returns goal + `place` + first `action` which is validated and executed before tick 1. All prompts are runtime templates — NPC authors never write LLM-handholding (user requirement).
- **Gemini perception wired into live mode** (was explore-only): `_wake_sweep` perceives all 5 views; `pulse_agent` perceives every tick's screenshot. Decision prompts got a "You See" section (landmarks/CHARACTER sightings with bearing+distance). **The decision LLM no longer receives pixels — any provider works.** The old "scan the ENTIRE image" handholding paragraph was removed.
- **Mental map builds in live mode**: all sweep/tick sightings are ingested into the agent's `spatial_map.json`; the LLM's own `place` naming (new JSON field in both wake and tick prompts) is ingested too → "Place:" line on future visits = "I have been here before".
- **Vision-guided directional movement** (prior handoff's next step): `walk_to direction=forward|forward-left|forward-right|left|right|back` resolves from current yaw (~15 m step, `_DIRECTION_YAW_OFFSET`); `wander` redefined as one step forward; rotation/facing injected into observation and prompts; per-direction map knowledge shown in prompts (`_direction_places`).
- **`unreal_bridge.py`**: `rotation` added to `get_observation`, new `set_facing` and `capture_view` methods.
- **`action_validator.py`**: `walk_to` accepts `direction`.

## Decisions locked in this session

- **The LLM judges, Unreal senses, Python accumulates** — e.g. LLM asks "is this a building?", a raycast answers, Python records it. Python never classifies/decides/routes behavior.
- **Gemini (flash-lite) is the eyes for everything** — wake sweep and live ticks, not just explore mode. Decision LLM is text-only and provider-agnostic.
- **Sim brains: Anthropic Haiku (thoughts) + Gemini (vision)**. OpenAI parked. Builder/director (Claude Code CLI) is never in the sim loop.
- **All orientation/handholding prompts are runtime system templates** — end users author only character/goals/rules markdown.
- **Wake = sweep + three questions + first action** — agents start moving before tick 1.
- **Web UI standalone sim control DEFERRED** (memory: `todo_webui_standalone`) — sim is driven via LLM/CLI/MCP until the core behavior loop is right. A read-only **mental-map viewer** (render `spatial_map.json`, maybe path recording) is wanted sooner.
- **Baby steps**: verify "where am I" before "what should I be doing"; don't add features until the current step is proven live.
- **Vision is the future "digital visual cortex" subsystem** (memory: `design_visual_cortex`): raycast grounds image→actor, LLM names it once, Python accumulates named things.
