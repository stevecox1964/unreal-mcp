## Decisions locked in this session

- **Pacing lives in the sim loop, not per-agent state** — interval = all agents' processing
  time + base (sleep after tick), so ticks can never pile up. Per-agent `tick_interval_seconds`
  stays as an optional extra throttle, default 0.
- **`reset_agents` only while PIE is running** — with PIE stopped, `GetGameWorld()` falls back
  to the editor world and the teleport would move the editor placements.
- **Start transforms are captured once** (first `start_simulation` after the keys are absent)
  and survive resets; delete `start_location`/`start_rotation` from `state.json` to re-capture.
- **Seed memories live in `memory.seed.json`** — authored separately from runtime `memory.json`
  so resets are lossless for character authoring.
- **WorldGrid and SpatialMap share the same tiling** (origin-anchored `floor(coord/cell_size)`,
  400 cm) — grid keys are also spatial-map cell keys; `world_grid.json` only adds bounds for
  stable col/row indexing.
- **`generate_world_grid` bounds need outlier review** — distant scenery (background mountains)
  inflates the box; exclude or hand-trim the JSON after generating.

## Open questions

(All carried over from the 06-06 handoff — none added this session.)

- **`mark_blocked` fragility** — the explorer still treats a no-path/never-started move the
  same as "arrived but obstructed", permanently blocking the frontier. Should only block after
  the avatar actually arrives near the cell and is then obstructed; skip-without-blocking on
  no-progress/timeout.
- **Sim-owned teleport-onto-navmesh at startup** — the new teleport command is a building
  block for this, but the "project to nearest navmesh point" logic doesn't exist yet.
- **Diff-gate leaves explore cells unlabeled** — fast ticks skip perception, so traversed
  cells can have empty landmarks. Now *more* relevant with 1 s base ticks.
- **Label canonicalization** — Gemini emits variants ("red barn"/"red barn with white trim")
  stored as separate tags.
- **Explore-mode re-targeting cadence** — with ~2.5–3 s effective ticks (was 10 s), `walk_to`
  re-issues mid-walk much more often; watch for frontier thrash, bump `tick_seconds` if needed.
