# Dream — APC movement, observation saving, memory, meeting people

**When:** 2026-06-24 23:08 CDT · **Iteration:** 1 · **Scope:** planning only
**Format:** "here is what I'd do" — each action is self-contained enough to hand to a subagent.

**Context (1 line):** observation is split — spatial facts go to `world_places.db` (good), but
everything episodic/social goes to a 30-item free-text `memory.json` that forgets on long runs and
has no record of *who an agent met* or *what happened where*. Backlog #5.

### Action 1.1 — Add an episodic observation store
**Goal:** persist a structured event every tick so "what happened where" is queryable, not free text.
**Files:** new `Python/agent_runtime/episodic_store.py`; call site in `agent_manager.py` `_act_agent`.
**Steps:**
1. New SQLite table (reuse `world_places.db` or a sibling) `episodes(agent_id, t, col, row, place,
   saw_json, action, outcome)`.
2. `EpisodicStore.record(agent_id, cell, observation, action, result)` — write one row per acted tick.
3. Call it from `_act_agent` after the action result is known.
**Done when:** a sim run produces episode rows for both agents with correct cell + action + outcome.
**Deps:** none. **Subagent-safe:** yes (Python + test).

### Action 1.2 — Add a per-agent social/acquaintance store
**Goal:** give agents memory of who they've met, where, when, how often.
**Files:** new `Python/agent_runtime/social_store.py`; populate from `agent_manager` observe/act.
**Steps:**
1. Table `acquaintances(agent_id, character, first_met, last_seen_t, last_cell, meet_count, sentiment)`.
2. `note_seen(agent_id, character, cell, t)` and `note_interaction(agent_id, character, kind)` upserts.
3. Populate `note_seen` from perceived `characters`; `note_interaction` from `say`/message events.
**Done when:** after Dufus greets Maren, Dufus's acquaintances row for Maren shows meet_count≥1 + cell.
**Deps:** none (1.1 optional). **Subagent-safe:** yes.

### Action 1.3 — Feed social memory into recall + perception
**Goal:** the agent's prompt knows "you've met Maren before near the market," not just "Maren is here."
**Files:** `memory_store.get_relevant_memories` (or the prompt assembly in `llm_router`/`agent_manager`).
**Steps:**
1. On building the decision prompt, look up acquaintances for currently-perceived characters.
2. Inject a short "known people" line (last seen where/when, meet count).
**Done when:** decision prompt for an agent near a known character includes that relationship line.
**Deps:** 1.2. **Subagent-safe:** yes.

### Action 1.4 — Memory consolidation pass (overnight-amnesia fix)
**Goal:** stop the 30-item cap from erasing long runs; keep durable summaries.
