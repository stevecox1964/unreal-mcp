# Unreal MCP Tools

> **Retired 2026-06-28.** The Python MCP **editor-authoring** tools documented below (actor, editor,
> blueprint, node, UMG, character, camera, project) were removed — use Epic's official Unreal MCP for
> editor authoring. The underlying C++ commands still exist in the plugin, but the Python MCP server
> now exposes only the **simulation control surface** (`simulation_tools.py`). These pages are kept
> for historical reference to the C++ command shapes.

This document is an index to all the tools supported.
